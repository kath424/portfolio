# Katerine Acosta — Portfolio

Personal portfolio of **Katerine Acosta**, Full Stack Software Developer
(React · JavaScript · Python · Flask · SQL), based in Mexico City.

Single static page (`index.html`, no build step) with a Spanish/English
toggle. Content is drawn from her professional experience:

- **Remesworld** — Software Engineer (SaaS money-transfer platform)
- **Renative Design** — Web Developer
- **Grupo Pineda** — WordPress / WooCommerce stores (freelance)

Plus selected projects from this GitHub account (4Geeks Academy
full-stack bootcamp and later practice projects).

## Run locally

Open `index.html` in a browser, or serve the folder with any static
server, e.g. `python3 -m http.server`.
